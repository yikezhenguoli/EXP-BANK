# EXP BANK v1.15.1

Touch-first Reward Sorting · v1.15.0 的触屏交互修复版。

## 本版重点

修复 Shopping Mall 奖励排序在手机端难以拖动的问题。v1.15.0 原先要求长按整张卡片，容易与 Android/iOS 原生文字选择、上下滚动手势冲突；尤其奖励集排序区域的纵向触摸策略会让浏览器优先接管纵向手势。

## 交互改动

- **独立拖动把手**：每条奖励和每个奖励集左侧新增明确的 ⠿ 拖动区域；只有从把手开始拖动，不再要求长按卡片文字。
- **按下即开始**：pointerdown 立即进入拖动状态，不再等待长按计时。
- **阻止系统抢手势**：把手使用 `touch-action:none`，按下时调用 `preventDefault()` 与 `stopPropagation()`，阻止原生文字选择、复制菜单与父级遮罩误触。
- **指针捕获**：拖动开始时捕获 pointer，松手或取消时释放；拖动过程继续使用 pointermove 计算目标位置。
- **滚动兼容**：列表保留纵向滚动；只有把手区域禁用原生触摸手势，避免整张卡片无法滚动。
- **单击备用排序**：奖励集行和奖励行右侧新增 ↑↓ 控件。奖励的上下移动限制在当前奖励集内；跨奖励集归类仍可通过把手拖到目标奖励集标题完成。
- **明确提示**：更新排序说明，不再使用含糊的“长按整条”。

## 数据安全

- 仍使用既有 `rewardCategories` 和 `rewards` 数组顺序保存展示顺序。
- 跨组移动只改变奖励的 `categoryId` 与数组位置。
- 不修改奖励成本、风险、图片、兑换历史、冷却信息或 EXP。
- 拖动草稿不进入主账本持久化数据；松手后统一保存。
- 不清空 localStorage，不要求重新导入备份。

## 测试

- 组件测试增加拖动把手必须立即启动、阻止默认文字选择、捕获并释放 pointer 的验证。
- 增加奖励集与奖励的 ↑↓ 单击排序测试。
- 原有跨奖励集拖动、组内顺序、备份恢复与资产字段保护测试继续保留。
- Service Worker 版本升级为 v1.15.1，并验证完整资源缓存后再激活。
